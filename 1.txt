## 🎯 PROJECT IDENTITY

**Vigil AI** is an open-source, 100% local, zero-trust security architecture that protects users from AI-era threats. It consists of TWO main components:

1. **Vigil Browser Shield** (Manifest V3 Chrome/Firefox extension): Real-time outbound DLP, anti-injection firewall, PII redaction
2. **Sentinel Agent Gateway** (Native Rust + Node.js companion): Policy enforcement layer for autonomous AI agents (MCP JSON-RPC, shell execution, file I/O, network requests)

**Core Philosophy:** 100% local, zero-trust, fail-closed, zero-cloud. NEVER send user data, prompts, or credentials to external servers.

**Step 1:** Open `src/manifest.json`

```json
  "alarms",
  "idle",
  "scripting" // <-- ADD THIS

```

**Step 3:** Remove the entire `"content_scripts"` block from manifest

**Step 4:** In `src/background/background.js`, add dynamic injection logic:
```javascript
// Register content scripts dynamically based on user interaction
async function registerContentScriptsForTab(tabId) {
  try {
    await chrome.scripting.executeScript({
      target: { tabId: tabId },
      files: ['content.js', 'detection-engine.js', 'secret-engine.js']
    });
  } catch (e) {
    console.warn('[VIGIL] Failed to inject scripts:', e);
  }
}

// Listen for user focus on input fields
chrome.webNavigation.onDOMContentLoaded.addListener((details) => {
  if (details.frameId === 0) {
    chrome.scripting.executeScript({
      target: { tabId: details.tabId },
      func: () => {
        document.addEventListener('focusin', (e) => {
          if (e.target.tagName === 'TEXTAREA' ||
              e.target.tagName === 'INPUT' ||
              e.target.isContentEditable) {
            chrome.runtime.sendMessage({ type: 'INJECT_VIGIL_SCRIPTS' });
          }
        });
      }
    });
  }
});

// Handle message from content script
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'INJECT_VIGIL_SCRIPTS' && sender.tab) {
    registerContentScriptsForTab(sender.tab.id);
  }
});
```

**Step 5:** Test manually:
- Open blank page → Check DevTools → No Vigil scripts loaded
- Click on textarea → Check DevTools → Vigil scripts injected
- Run `npm test` → All tests pass
